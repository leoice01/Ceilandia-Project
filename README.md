# Ceilandia Project

Repositório da equipe do jogo **Polícia e Ladrão PvP** (Roblox), sincronizado com Roblox Studio via Rojo.

## Como rodar

1. Instale o [Rokit](https://github.com/rojo-rbx/rokit).
2. Na raiz do projeto, instale as ferramentas: `rokit install`.
3. Inicie o servidor local: `rojo serve`.
4. Instale o plugin do Rojo no Roblox Studio.
5. Abra o place **Ceilandia** no Studio, abra o plugin do Rojo e clique em **Connect**.

> **Aviso:** Antes de conectar o Rojo pela primeira vez, salve um backup `.rbxl` do place (`File > Save to File`).

Documentação do projeto: `docs/design.md`, `docs/decisoes.md` e `docs/fases/`.
